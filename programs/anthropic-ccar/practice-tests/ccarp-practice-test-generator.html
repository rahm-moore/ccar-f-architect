CCAR-P Practice Test Generator

Builds a timed or untimed attempt from a 155-question bank, weighted to CCAR-P's 7 domains. Click the domain cards below to include/exclude them, pick a question count and pace, then Start Attempt. Score history (including elapsed time) is saved in this browser.
Domain weights and exam format are from third-party sources (tutorialsdojo.com, claudecertificationguide.com, and CertMasterClass.com's independent CCAR-P prep course), cross-checked against each other but not yet confirmed against Anthropic's own official CCAR-P materials.

Question set: every question is tagged "Original" or "Generic". Generic (51 questions) are written to match documented domain topics in plain, industry-standard language — the safer baseline set. Original (104 questions) covers the same ground grounded in the official Anthropic Academy CCAR-P Prep Course lesson docs and in facts/figures drawn from CertMasterClass.com's companion guide, flashcards, and practice assessments, but every question has been written from scratch into original scenarios — no vendor's question text, course-specific named framework, product terminology, or close paraphrasing of source material remains. Both sets are original authorship and test the same underlying architecture/ops concepts. If you intend to reuse, publish, or sell any version of this quiz, use the "Original only" filter and have someone independently check it against the source material first — this project's own authoring process is not a substitute for that review.

Difficulty: every question is also tagged Less challenging, Challenging, or Very challenging, based on how much multi-step reasoning or precise recall it demands.

Timed attempts: pick a question count, a seconds-per-question pace (or "No timer"), and which domains to include below, then click Start Attempt — this approximates the real CCAR-P exam's structure (63 scenario-based questions, ~120 minutes, 720-of-1000 i.e. 72% to pass) for practice pacing, but the timer, question count, and weighted scoring here are this tool's own approximation, not an official Pearson VUE interface or scoring formula. Narrow filters/domains can return fewer questions than requested — the bank isn't evenly split across every combination, especially for the smallest domain (Developer Productivity, 7%).
