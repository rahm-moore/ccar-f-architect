CCAR-P Practice Test Generator

Pulls a fresh, randomized question set (up to 45) each time from a 112-question bank, weighted to CCAR-P's 7 domains (Integration 19%, Solution Design 17%, Evaluation/Testing/Optimisation 16%, Governance/Safety/Risk 14%, Stakeholder Communication/Lifecycle 14%, Claude Models/Prompting/Context Engineering 13%, Developer Productivity/Operational Enablement 7%). Use the Difficulty and Question set controls below to narrow what gets pulled in. Score history saved in this browser.
Domain weights and exam format are from third-party sources (tutorialsdojo.com, claudecertificationguide.com), cross-checked against each other but not yet confirmed against Anthropic's own official CCAR-P materials.

Question set (refactored in this update): every question is tagged "Original" or "Generic". Generic (55 questions) are written to match documented domain topics in plain, industry-standard language — the safer baseline set. Original (57 questions) covers the same ground once grounded in the official Anthropic Academy CCAR-P Prep Course lesson docs, but has been rewritten from scratch into original, genericized scenarios — no course-specific named frameworks, product terminology, or close paraphrasing of lesson text remain. Both sets are original authorship and test the same underlying architecture/ops concepts; "Generic" just stays further from that specific course's framing. If you intend to reuse, publish, or sell any version of this quiz, use the "Original only" filter and have someone independently check it against the source material first — this project's own authoring process is not a substitute for that review.

Difficulty (added in this update): every question is also tagged Less challenging, Challenging, or Very challenging, based on how much multi-step reasoning or precise recall it demands. Narrowing both filters at once can return fewer than 45 questions for a run — the bank isn't evenly split across every combination, especially for the smallest domain (Developer Productivity, 7%).
